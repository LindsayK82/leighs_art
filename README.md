# LeighsArt2
This website was created by Lindsay Klug, for the use of the artist, Leigh Witherell. The site in corporates an artist dashboard, allowing the artist full control of their website without the need to contact a website admin for every change. This solved a key need for this artist.

## Features
Features for this dynamic website include an artist dashboard, where the artists can upload, edit, and delete images into different galleries as they please. They can also edit their CV, Press, and Installations through the dashboard. The shopping page has a cart that moves with the page, and when clicked expands a sidebar with the cart selections and a continue to PayPal button. Each gallery has selected images, and any image can be featured on the home page without the HTML having to change.
